# Proyecto Tritón

Sistema de Telemetría Multicloud y Observabilidad Asíncrona

### Características

- Consulta estados de los clúster en tiempo real
- Muestreo de datos legible al humano

### Tecnologías

- Python
- pip

### Requisitos

- Python 3.0+

## Instalación

1.  Clonar el repositorio

    1. Ve a la carpeta donde quieres guardar el proyecto:
        
        ```bash
        cd ruta/de/la/carpeta
        ```
    2. Clona el repositorio
        
        ```bash
        git clone git@github.com:leoventicola/TP1-Triton-project.git
        ```
    3. Entra al proyecto
        
        ```bash
        cd TP1-Triton-project
        ```

2. Instalar dependencias
    
    1. Crear el entorno virtual

        Dentro de la carpeta del proyecto:
        
        ```bash
        python -m venv venv
        ```
        
        Esto crea una carpeta llamada `venv`.
    
    2. Activarlo

        - Windows (CMD):
        
        ```bash
        venv\Scripts\activate
        ```

        - Windows (PowerShell):

        ```bash
        .\venv\Scripts\Activate.ps1
        ```

        - Linux / macOS:
            
        ```bash
        source .venv/bin/activate
        ```

        Cuando esté activado, normalmente verás algo como:

        ```bash
        (.venv) $
        ```

    3. Instalar paquetes:
    
        Con el entorno activado:

        ```bash
        pip install -r requirements.txt
        ```
